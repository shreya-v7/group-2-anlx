Can a small AI model summarize job postings for career advisers?

The question

A university career office wants short, source-linked summaries of job postings (title, employer, location, work arrangement, requirements) that an adviser checks before students see them. Not hiring decisions.

Finding 2: formatting hid answers

The model wrapped its JSON in Markdown fences, so the strict checker rejected all 50 structured answers. Stripping the fences afterwards gave 43/50 valid, 31/50 source-correct: a diagnosis, not a new result.

A checker that refuses anything unverified (C4) blocked all 50 answers. Perfectly safe, completely useless.

Finding 5: repair, don’t withhold

A second API (Tech, same model) stripped fences and repaired answers against the posting: 39/50 usable (34 strict). With the same fence fix, Pharma’s strict verifier would have passed 31/50. Still 0/25 hand-labeled Tech records fully right; 5 of 6 discriminatory postings passed its guardrail.

Recommendation

  • Copy facts already in the source table directly: no AI needed.
  • Use the AI only as a supervised research tool, with an adviser checking every answer.
  • Never for ranking applicants or eligibility decisions.
  • Next: enforce JSON at decoding time, screen postings for discriminatory terms, test on new employers.
