# Poster (editable HTML)

`poster.html` is the 36 x 24 inch poster. Open it in any browser; it scales to fit the window.

**Edit text:** change the words directly in `poster.html`.

**Edit a bar:** each bar has a number and a `style="--v: N"`. Set N to the bar's length as a percent:
- Finding 1: N = count out of 50 x 2 (e.g. 17/50 -> 34)
- Finding 3: N = percent blocked (e.g. 3/5 -> 60)
- Finding 4: N = seconds / 400 x 100 (e.g. 330 s -> 82.5)

**Export PDF:** Chrome > Print > Save as PDF, Margins: None, Background graphics: on (the 36x24 page size is set automatically).
Or headless: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-pdf-header-footer --print-to-pdf=poster.pdf poster.html`

`poster_from_html.pdf` is the current export. The submitted poster PDF is `../documents/Scientific_Poster_36x24.pdf` (same content, generated by `../build/build_poster.py`).
